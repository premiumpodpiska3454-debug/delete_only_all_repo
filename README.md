# 🧹 GitHub Repository Cleaner

> ⚡ **Повне очищення GitHub від усіх власних репозиторіїв за один запуск.**

## 🚨 ⚠️ УВАГА — ПРОЧИТАЙ ПЕРЕД ВИКОРИСТАННЯМ!

**Цей скрипт призначений для ПОВНОГО ВИДАЛЕННЯ ВСІХ ВЛАСНИХ GitHub-репозиторіїв.**

Після підтвердження `DELETE` скрипт послідовно видалить **усі репозиторії**, які повертає GitHub API для твого облікового запису.

### ❗ Видалення може бути НЕЗВОРОТНИМ!

Разом із репозиторіями можуть бути втрачені:

* 📁 файли та код;
* 📝 README;
* 🐛 Issues;
* 🔀 Pull Requests;
* ⭐ Stars;
* 🏷️ Releases;
* 📦 інші дані репозиторіїв.

**Перед запуском переконайся, що в репозиторіях немає нічого важливого.**

---

# 💥 Що робить цей скрипт?

`GitHub Repository Cleaner` автоматизує повне очищення власних репозиторіїв.

```text
🔑 GitHub Token
       ↓
🔎 Перевірка авторизації
       ↓
📋 Отримання ВСІХ репозиторіїв
       ↓
⚠️ Показ повного списку
       ↓
⌨️ Потрібно ввести DELETE
       ↓
🗑️ Видалення репозиторіїв
       ↓
📊 Фінальний результат
```

Ніяких ручних переходів:

```text
Repository → Settings → Delete
```

для кожного репозиторію окремо.

# 🔑 GitHub Token

Після запуску скрипт сам попросить Token:

```text
🔑 Введи GitHub Token:
```

Token вводиться **приховано** — символи не відображаються в терміналі.

Тобі не потрібно:

```bash
export GITHUB_TOKEN="..."
```

і не потрібно записувати Token безпосередньо в Python-файл.

# ▶️ Запуск

```bash
python3 delete_all_repos.py
```

Після запуску:

```text
======================================================================
🗑️ УДАЛЕННЯ GITHUB РЕПОЗИТОРІЇВ
======================================================================

🔑 Введи GitHub Token:
```

Після успішної авторизації:

```text
🔎 Перевіряю токен...
✅ Авторизація успішна: username
```

# 📋 Перед видаленням

Скрипт **спочатку отримує та показує список усіх репозиторіїв**:

```text
======================================================================
📋 НАЙДЕНІ РЕПОЗИТОРІЇ
======================================================================

  1. username/project1
  2. username/project2
  3. username/test
  4. username/api-test
  5. username/123
  ...
  
======================================================================
📊 Всього знайдено: 49
```

Це дає можливість перевірити, **що саме буде видалено**.

---

# 🔥 Підтвердження

Після показу списку скрипт запитає:

```text
⚠️ УВАГА!
Видалення репозиторіїв незворотне.

Для видалення ВСІХ цих репозиторіїв введи DELETE:
```

Тільки якщо ввести:

```text
DELETE
```

почнеться видалення.

Будь-який інший текст:

```text
⛔ Скасовано. Нічого не видалено.
```

# 🧠 GitHub API

Скрипт працює через офіційний GitHub REST API.

Використовуються операції:

```text
GET /user
```

Для перевірки авторизації.

```text
GET /user/repos
```

Для отримання списку репозиторіїв.

```text
DELETE /repos/{owner}/{repo}
```

Для видалення кожного репозиторію.

---

# 🛡️ Захист від випадкового видалення

Скрипт має кілька перевірок:

### 1. Перевірка Token

```text
🔎 Перевіряю токен...
```

### 2. Отримання списку

```text
📋 НАЙДЕНІ РЕПОЗИТОРІЇ
```

### 3. Показ кількості

```text
📊 Всього знайдено: 49
```

### 4. Явне підтвердження

```text
DELETE
```

Без правильного слова `DELETE` жоден репозиторій не видаляється.

---

# 🚀 Коли це корисно?

Наприклад, якщо GitHub використовувався для тестування API і було створено багато тимчасових репозиторіїв:

```text
2
3
4
5
6
7
...
50
```

Замість видалення кожного вручну можна виконати:

```bash
python3 delete_all_repos.py
```

і очистити весь список за один запуск.
