# 🚀 GitHub Repository Cleaner

> 🧹 **Простий, зрозумілий та безпечний інструмент для масового видалення власних GitHub-репозиторіїв**

---

## 💥 Що це?

**GitHub Repository Cleaner** — невеликий Python-скрипт, який дозволяє швидко очистити свій GitHub від тестових репозиторіїв.

Особливо зручно, якщо ти створив багато репозиторіїв під час:

* 🧪 тестування GitHub API;
* 🤖 розробки ботів;
* 💻 експериментів із Python;
* 🔧 перевірки автоматизації;
* 🚀 навчання роботі з GitHub API.

Замість того щоб видаляти десятки репозиторіїв вручну через вебінтерфейс — запускаєш один скрипт.

# 🎯 Як це працює?

Усього **4 прості кроки**:

```text
        🔑
   Вводиш Token
       │
       ▼
    🔎 GitHub
   перевіряє Token
       │
       ▼
    📋 Отримуємо
   список репозиторіїв
       │
       ▼
    ⚠️ Підтвердження
       │
       ▼
      🗑️
   Видалення
```

# 🔐 GitHub Token

Після запуску програма сама попросить:

```text
🔑 Введи GitHub Token:
```

### 👀 Важливо

Під час введення Token **символи не відображаються**.

Це нормально.

Наприклад:

```text
🔑 Введи GitHub Token: 
```

Ти вводиш Token і натискаєш:

```text
Enter
```

---

# 🛡️ Token не потрібно вставляти в код

Це одна з головних переваг.

❌ Не потрібно:

```python
TOKEN = "ghp_xxxxxxxxxxxxx"
```

❌ Не потрібно:

```bash
export GITHUB_TOKEN="..."
```

❌ Не потрібно зберігати Token у файлі.

Скрипт запитує його **під час запуску**.

---

# 🔎 Перевірка Token

Після введення скрипт перевірить авторизацію:

```text
🔎 Перевіряю токен...
✅ Авторизація успішна: username
```

Якщо Token неправильний:

```text
❌ Токен не працює.
```

І програма зупиниться.

---

# 📋 Перегляд репозиторіїв

Перед видаленням програма покаже список:

```text
======================================================================
📋 НАЙДЕНІ РЕПОЗИТОРІЇ
======================================================================
  1. username/2
  2. username/3
  3. username/4
  4. username/5
  5. username/6
  ...
 49. username/50
======================================================================
📊 Всього знайдено: 49
```

### 😎 Це дуже важливо

Ти **бачиш, що саме буде видалено**, перш ніж програма почне роботу.

# ⚠️ Підтвердження

Перед видаленням програма попросить:

```text
⚠️ УВАГА!
Видалення репозиторіїв незворотне.

```

```text
DELETE
```

Якщо ввести щось інше:

```text
⛔ Скасовано. Нічого не видалено.
```

# 🚨 Безпека

## ⚠️ УВАГА

Видалення GitHub-репозиторію може бути **незворотним**.

Після видалення можна втратити:

* 📁 файли;
* 📝 README;
* 🐛 Issues;
* 🔀 Pull Requests;
* ⭐ Stars;
* 📦 Releases;
* 📊 історію репозиторію.

Тому **обов'язково перевір список перед введенням `DELETE`**.

---

# 🔑 Які права потрібні Token?

Token повинен мати права, необхідні GitHub API для:

```text
видалення власних репозиторіїв
```

Не надавай Token зайвих дозволів, які цьому скрипту не потрібні.

---

# 🧠 Як працює API?

Скрипт використовує GitHub REST API.

Основні операції:

```text
GET /user
```

🔎 Перевірка користувача.

```text
GET /user/repos
```

📋 Отримання репозиторіїв.

```text
DELETE /repos/{owner}/{repo}
```

🗑️ Видалення конкретного репозиторію.
